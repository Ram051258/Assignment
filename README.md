- ##### Clone Framework
    <pre>
    git clone https://github.com/ram051268+/automation-testing-python-selenium.git</pre>
- ##### Copy the web_ui_testing folder to your project location and open command prompt from there.
    
- ##### Create and activate virtual environment
    <pre>
    python -m venv ENVIRONMENT_NAME
    ENVIRONMENT_NAME\scripts\activate</pre>
- ##### Install required Python Packages
    <pre>
    pip install -r requirements.txt</pre>
- ##### Run the test
    <pre>
    type the command "pytest" in the same command prompt</pre>
